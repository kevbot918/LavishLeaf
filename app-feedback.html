A bug, a station that will not play, an idea you would like built. It reaches one person, and that person reads all of it.

Before you write

If a single recording will not play, it is usually the archive that holds it rather than the app. Symphonymph never keeps a copy, so when a library moves a file the link goes with it. Telling us which recording is exactly what we need to hear: those get fixed by pointing the app somewhere better.

If you are sending this from the app itself, the version, your Android version and your phone model are attached automatically. From this page, please say what they are. You will find them in the app under Settings, at the very bottom.

Only so we can reply or ask a follow-up question. It is never added to a mailing list.
